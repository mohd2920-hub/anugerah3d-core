# Project Rules

- Use Laravel.
- Use MariaDB.
- Use S3 bucket: anugerah3d-content.
- Public site: anugerah3d.com.
- Admin portal: admin.anugerah3d.com.
- Agent portal: agent.anugerah3d.com.
- Customer portal: customer.anugerah3d.com.
- Laravel source code must be inside /src.
- Do not commit .env.
- Use database naming: adm_name, agt_name, cust_name, prd_name.
- Store picture fields as S3 object keys, not full URLs.
- Log important actions into activities table.
